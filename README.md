# Railway Management System

A **Railway Management System** database project designed to manage and organize railway-related information using relational database concepts.

The project focuses on **database design, normalization, schema development, and structured railway data management**.

## Overview

The Railway Management System provides a structured database for storing and managing information related to railway operations. The project demonstrates important **DBMS concepts** such as:

* Relational database design
* Entity-Relationship modeling
* Database normalization
* Schema design
* SQL table creation
* Data organization and management
* Relationships between multiple entities

## Database Design

The project follows a structured relational database approach where railway-related entities are represented using tables and connected through appropriate relationships.

The database design aims to:

* Reduce data redundancy
* Maintain data consistency
* Establish relationships between entities
* Improve data integrity
* Organize information efficiently

## Normalization

The database is designed using normalization principles to minimize redundancy and avoid common database anomalies.

The normalization section demonstrates the transformation of data into well-structured relations using concepts such as:

* **First Normal Form (1NF)**
* **Second Normal Form (2NF)**
* **Third Normal Form (3NF)**

Normalization helps ensure that each table stores logically related information while maintaining appropriate relationships between tables.

## Schema

The `Schema` directory contains the database structure, including definitions of the tables and their relationships.

The schema represents the logical organization of the Railway Management System and provides the foundation for storing railway-related data.

## Data

The `Data` directory contains the data used to populate and demonstrate the database.

This allows the database design and relationships to be tested with sample records.

## How to Use

### 1. Clone the Repository

```bash
git clone https://github.com/iparigoel/Railway-Management-System.git
```

### 2. Open MySQL

Open MySQL Workbench, MySQL Command Line, or another compatible MySQL client.

### 3. Create the Database

Run the SQL files available in the `database` and `Schema` directories according to their dependencies.

### 4. Insert Data

Use the SQL files in the `Data` directory to populate the database with sample records.

### 5. Explore the Database

After importing the schema and data, you can execute SQL queries to explore the railway database and analyze the relationships between different entities.
